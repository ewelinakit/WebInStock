# WebInStock
Ціль проекту: Створення інструменту для ефективного обліку товарів на складі або в магазині. Веб-застосунок дозволяє користувачам розміщувати детальні обліки товарів, слідкувати за їхнім рухом, контролювати залишки, робити замовлення та забезпечувати легкий доступ до інформації про товари.
